# Model Rush

AI 大模型训练模拟经营游戏。扮演一家 AI 公司，从购买 GPU 开始，训练顶尖大模型，与全球九大 AI 厂商竞争排行榜。

---

## 快速开始

用浏览器直接打开 `index.html` 即可，无需安装任何依赖。

依赖通过 CDN 加载：
- Three.js（3D 渲染）
- Tailwind CSS（界面样式）

---

## 游戏概述

### 目标

训练出排行榜第一的 AI 模型，成为行业标杆。

### 时间系统

- 1 真实秒 = 1 游戏天（1x 速度）
- 支持 1x / 2x / 5x 速度，可暂停
- 游戏持续运行，非回合制

### 初始资源

- 现金：$500,000,000（5 亿美金）
- 供电容量：2 MW
- 冷却容量：3 MW
- 数据中心：200 个机架位

---

## 核心玩法

### 1. 购买 GPU

点击底部"购买 GPU"按钮，选择 GPU 型号和机架数量。

- 1 个机架 = 8 张 GPU
- 9 款 GPU 可选，从 NVIDIA A100 到 Rubin，AMD MI300X/MI325X
- 不同 GPU 有不同算力、显存、功耗和价格
- 每种 GPU 型号最多 2000 张
- GPU 以 3D 机架形式显示在数据中心场景中

### 2. 拆除 GPU

点击底部"拆除 GPU"按钮，选择型号和数量。
- 拆除返还购买价的 50%
- 对应 3D 模型自动移除

### 3. 管理供电和冷却

**供电**：GPU 运行需要电力。总功耗超过供电容量会触发断电。

- 总功耗 = GPU 功耗 x (1 + 冷却系数 0.30)
- 扩容供电：$50,000,000 / MW
- 断电持续 3 天，期间训练中断，5 次中断后训练崩坏

**冷却**：GPU 散热需要冷却系统。冷却容量 >= GPU 功耗的 30%。
- 扩容冷却：$20,000,000 / MW
- 冷却不足时，训练效率降低 30%，持续 7 天

### 4. 扩容数据中心

- 初始 200 个机架位（10 行 x 20 列）
- 每次扩容增加 2 行 x 4 列
- 扩容费用递增：$200M、$400M、$600M...
- 最多扩容 5 次

### 5. 训练模型

点击"新建训练"配置训练任务：

**模型规模**：
- 小型（1B）：快速实验，训练快
- 中型（70B）：主力产品，平衡性价比
- 大型（400B）：旗舰模型，竞争必备
- 前沿（1T+）：冲击 SOTA，需要大量资源

**数据质量**：
- 低质量（免费，分数 -30%）
- 中等质量（$10M，无加成）
- 高质量（$100M，分数 +20%）
- 极高质量（$500M，分数 +40%）

**对齐方法**：
- RLHF + PPO：高质量，高成本（$50M）
- DPO：低成本，稳定（$10M）

**技术选择**（12 项，全部可用）：
- 训练优化：Flash Attention、Mixed Precision、GQA、ZeRO-3、3D Parallelism、Multi-Token Prediction
- 模型架构：Sparse Attention、MoE
- 对齐推理：Constitutional AI、Knowledge Distillation、Quantization-Aware Training、Speculative Decoding

> 训练时显示预估功耗和当前总功耗，方便规划供电扩容。

**开源策略**：
- 闭源：产生 API 收入
- 开源：无 API 收入，但社区传播可能带来间接收益

**放弃训练**：训练进行中可点击右侧面板的"放弃训练"按钮。

### 6. 聘请研究员

点击"聘请研究员"按钮，选择研究员等级：

| 等级 | 月薪 | 训练效率加成 | 最多 |
|------|------|-------------|------|
| 初级研究员 | $1,000,000 | +2% | 5 位 |
| 高级研究员 | $3,000,000 | +4% | 5 位 |
| 首席研究员 | $6,000,000 | +6% | 5 位 |

研究员效率加成对所有训练任务生效，不同等级可以叠加。

### 7. 融资

- 每 180 天可融资一次
- 融资金额基于排行榜排名
- 排名第一可获 $10B，排名越高融资越多

### 8. 收入来源

**API 收入**（每日）：
- 来自已部署的闭源模型
- 收入 = DAU x 日均 token 数 x token 单价
- 受到 Speculative Decoding 等技术加成

**企业授权收入**（每月）：
- 基于模型排行榜排名
- 排名越高，授权收入越多

## 竞争对手

九大 AI 厂商，各有不同实力和风格：

| 厂商 | 风格 | 开源 | 梯队 |
|------|------|------|------|
| OpenAI | 闭源霸主，综合最强 | 否 | Tier 1 |
| Anthropic | 安全对齐标杆 | 否 | Tier 1 |
| Google | 多模态王者 | 否 | Tier 1 |
| DeepSeek | 中国开源先锋 | 是 | Tier 2 |
| Kimi | 中国推理新锐 | 否 | Tier 2 |
| GLM | 智谱AI，产学研标杆 | 是 | Tier 2 |
| xAI | 马斯克旗下，算力庞大 | 否 | Tier 2 |
| Qwen | 阿里通义，MoE效率之王 | 是 | Tier 3 |
| Minimax | 多模态新势力 | 否 | Tier 3 |

竞争对手会在 45~120 天间隔发布新模型，分数会逐渐提升。

**梯队系统**：厂商按实力分为三个梯队，排名更加稳定：
- Tier 1（OpenAI, Anthropic, Google）：增长缓慢，上限 95，基本不会掉出前三
- Tier 2（DeepSeek, Kimi, GLM, xAI）：中等增长，上限 90
- Tier 3（Qwen, Minimax）：快速增长，上限 85

## 随机事件

每 30~90 天触发一次随机事件：

| 事件 | 效果 |
|------|------|
| 硬件故障 | 损失 2% GPU |
| 电网波动 | 停电 2 天 |
| 数据泄露 | 罚款 $100M |
| 人才挖角 | 训练效率 -20%（15 天） |
| 技术突破 | 当前训练加速 20% |
| 政策利好 | 获得补贴 $500M |
| 开源冲击 | API 收入 -30%（30 天） |
| 芯片禁运 | 禁止购买 GPU（30 天） |
| 行业盛会 | 估值 +15% |
| 算法突破 | 下次训练效率 +30% |

## 界面说明

右侧面板使用标签页布局，点击标签切换不同内容：

- **财务**：收入/支出/利润/现金流，基础设施状态（供电、冷却、GPU总数、研究员）
- **训练**：当前训练进度、阶段、剩余天数、放弃训练按钮
- **排行**：全球模型排行榜
- **库存**：GPU 库存明细
- **日志**：事件日志

面板左侧有拖拽手柄，可拖动调整面板宽度。

底部操作栏：购买GPU | 拆除GPU | 扩容供电 | 扩容冷却 | 扩容机房 | 聘请研究员 | 新建训练 | 融资
