# Model Rush · 论坛版

在 NodeLoc 内经营自己的 AI 公司：采集数据、研发技术、购买 GPU、并行训练模型，再部署模型赚取收入。它保留了网页版的全部经营规则，并改用 NodeLoc 原生 Blocks 操作界面。

## 怎么玩

1. 从六类数据源发起实时采集；各自有成本、质量、类别与到账时长。
2. 购买九种 GPU，注意市值解锁、机房位、供电和冷却；闲置 GPU 可拆除回收 50% 成本。
3. 在完整研发树中推进 4 级技术与依赖关系，每项技术可升至 Lv.3；也可聘请不同等级研究员。
4. 自由配置模型名称、1B–2000B 参数、GPU 型号与数量、DPO/RLHF、开源策略和已解锁训练技术。训练支持并行、暂停、检查点回滚、放弃与训练事件。
5. 完成训练后可自动或手动部署；部署支持异构 GPU 等效算力、调配、下架与收入结算。开源模型也有收入，但低于闭源模型。
6. 每天结算电力（含冷却）、网费、人员支出与模型收入，并有融资冷却、随机事件、芯片禁运、断电等经营风险。
7. 每个 NodeLoc 账号可创建、切换和删除多个独立存档。

进度按 NodeLoc 账号独立保存，与网页版 Model Rush 存档互不影响。Blocks 不支持 Three.js，因此只有 3D 机房画面以资源面板呈现；其机架位、型号、等效算力与功耗规则均保留。
