# Model Rush · 论坛版

在 NodeLoc 内经营自己的 AI 公司：采集数据、研发技术、购买 GPU、并行训练模型，再部署模型赚取收入。

## 怎么玩

1. 点击「采集 10B 数据」建立采集任务；数据会在两天后到账。
2. 购买 GPU 后，按紧凑、标准或前沿规格启动训练；多个任务会共享闲置 GPU。
3. 选择研发项目。数据清洗提高采集量、优化器加快训练、推理引擎提高部署收入；每项可升至 Lv.3。
4. 每次「推进一天」都会结算部署收入、GPU 成本，以及采集、研发和训练进度。
5. 训练完成的模型需手动部署，部署会占用 4 张 GPU 并带来持续收入；暂停训练会立即释放其 GPU。

进度按 NodeLoc 账号独立保存。此版本是为论坛原生界面设计的轻量玩法，与网页版 Model Rush 互不影响。
